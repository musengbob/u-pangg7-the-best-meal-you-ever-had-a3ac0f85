An entry for [The Best Meal You Ever Had](https://make.fun) on make.fun.

One sentence, at most 200 characters, about the best meal ever had: my
grandmother's rendang, eaten cross-legged on the kitchen floor at
midnight, the coconut milk still bubbling, and nobody speaking because
the food was doing all the talking.

## How it works

`main.ts` writes the entry sentence to `/output/entry.txt` (resolved via
`$MAKEFUN_OUTPUT_DIR`, falling back to `$OUTPUT_PATH`, then `/output`
inside the grader sandbox, then a local `output/` directory). Run it
locally with:

```sh
node main.ts
```
